# 画面の動きと設定

## 周回

`build()` に `spiral` を渡さなければ、`auto_spiral()` が周を組みます。

- 各問題に「分野の中で何番目か ÷ 分野の問題数」の値を付けて並べ、10問前後ずつに切ります。問題の多い分野ほど各周に多く入り、どの周にも全分野が入ります（分野の問題数が周の数より少ないときは、入らない周があります）
- 分野の中では書いた順に前の周へ入ります
- 周の並びを自分で決めたいときは、`spiral=dict(rounds=[[id, ...], ...], dom={id: '分野名'})` を渡します。`dom` は周の結果画面で「間違えた問題の分野」の集計に使います

### 解き方の流れ

1. 初めて開くと第1周から始まります
2. 周を解き終えると結果画面が出ます。間違いが残っていれば「間違えたN問を解き直す」が先頭のボタンになり、全問正解になると「次の周へ進む」に替わります
3. 「成績・設定」の周の一覧から周を押すと、入口の画面で「最初から解き直す」「続きから」「間違えた問題だけ」を選べます

「最初から解き直す」は、押した時刻より前の解答をその周では未回答として扱います。記録は消さないので、成績の表（最新・初回の正答率）には残ります。

### ほかの解き方

「成績・設定」から次も選べます。

- **全問を通しで解く**：分野の順に全部
- **間違えた問題だけ**：全問のうち、最新の解答が不正解のもの
- **本番形式**：`build(mock=dict(scenarios=2, per=5))` を渡したときだけ出ます。`per` 問以上ある分野から `scenarios` 個を無作為に選び、通しで解きます

## 記録の保存と同期

既定では、記録はブラウザの localStorage に `key` の名前で保存します。ブラウザごとに別の記録です。

端末間で同期したいときは、保存用のAPIを用意して `sync` を渡します。

```python
builder.build(..., sync=dict(url='https://example.com/state/my-quiz', headers={'x-api-key': '…'}))
```

APIに求めるのは2つだけです。

- `GET <url>` → `{"state": {...}}` を返す（まだ無ければ `{}`）。ログインが要るなら `401` を返すと、画面に「この端末にだけ保存中」と出ます
- `PUT <url>` 本文 `{"state": {...}}` → 保存して `2xx` を返す

画面は保存の前にAPIの記録を読み、問題ごとに新しいほうの解答を採ってから書き戻します。周の解き直しの起点も、周ごとに新しいほうを採ります。認証はブラウザのクッキー（`credentials: 'same-origin'`）か `headers` で渡します。`headers` は HTML に埋め込まれるので、秘密の値は入れないでください。

## 操作

- PC：1〜5 か a〜e で選択、← → か Enter でめくる、Esc でメニューを閉じる
- スマホ：左右のスワイプでめくる

## 見た目を変える

配色は `drillkit/template.html` の先頭の CSS 変数（`--blue-*` など）にまとめてあります。
